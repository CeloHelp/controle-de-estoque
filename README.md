# Sistema de Controle de Estoque - Amortecedores

Este projeto é um sistema simples de controle de estoque para uma empresa de amortecedores de carros e camionetes, desenvolvido com Express.js.

## Como executar

1. Instale as dependências:
   ```powershell
   npm install
   ```
2. Inicie o servidor:
   ```powershell
   node index.js
   ```
3. Acesse: http://localhost:3000

## Funcionalidades previstas
- Cadastro de itens no estoque
- Consulta de itens
- Atualização de itens
- Remoção de itens

## Estrutura sugerida
- `routes/` - Rotas da API
- `controllers/` - Lógica de negócio
- `models/` - Modelos de dados
